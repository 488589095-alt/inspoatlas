# InspoAtlas「灵感图谱」PRD

## 1. 产品定义

InspoAtlas 是面向 UI/产品设计师的中文 AI 灵感工作台。它通过桌面 Web 与浏览器插件收集图片、网页和文字，在无限画布中建立空间关系，并将素材转成可直接用于设计和前端协作的标准资产包。

工作名为 **InspoAtlas / 灵感图谱**。产品承诺不是替用户做设计，而是让混乱的参考变得清楚、可验证、可复用。

## 2. 用户与任务

### 主要用户

- 独立或团队中的 UI/产品设计师。
- 日常使用浏览器、截图、Figma 和文档工具。
- 每个项目会收集几十至数百个界面、网页、文案或局部组件参考。

### 核心 JTBD

当我为新项目寻找视觉方向时，我希望先快速收集而无需当场分类，再让系统帮我理解相似点、拆出可用元素并保留来源，这样我能更快将参考转成设计规范，而不是重新翻找和手工抄录。

## 3. 信息架构

- `/`：产品入口与登录态分流。
- `/boards`：画布列表、最近素材、额度、示例和导入入口。
- `/boards/:id`：无限画布工作台。
- `/share/:token`：只读分享。
- `/settings/ai`：平台额度、BYOK 测试/替换/删除。

画布工作台固定为四区：左侧画布与素材导航、中部无限画布、右侧属性/AI 面板、底部保存/分析/缩放状态。

## 4. 核心流程

### 4.1 激活

1. 用户使用邀请码和邮箱验证码进入。
2. 系统创建私有空间和示例画布。
3. 引导用户粘贴一张截图、一个网页或一段文字。
4. 首次分析完成后，突出“确认元素”和“导出资产包”。

### 4.2 采集

- 图片：拖拽、文件选择或剪贴板；仅 JPG、PNG、WebP，单文件不超过 20 MB。
- 文字：粘贴或创建便签，最多 50,000 字符。
- 网页：粘贴公开 URL，或通过插件主动采集。
- 插件采集来源 URL、标题、全页截图、可读正文和关键元素计算样式；不采集 Cookie，不在后台运行。
- 公开 URL 抓取失败时生成链接卡并说明失败原因，不丢失用户输入。

### 4.3 单素材分析

分析结果必须符合统一结构：摘要、用途、OCR/文案、风格/情绪/行业标签、主辅色和占比、字体推断、圆角/间距/阴影、布局、组件、可访问性提醒、区域坐标、置信度和来源。

分析状态为 `idle → queued → processing → ready | failed`。失败不扣额度；重试保持同一幂等键。结构校验失败时自动修复一次。

### 4.4 元素确认

AI 在素材上叠加候选区域。用户可以移动、缩放、删除候选框并确认；确认后生成元素子素材和 `derived-from` 关系。未经确认的候选不进入导出包。

### 4.5 搜索与关系

- 混合搜索覆盖标题、OCR、正文、标签、颜色和语义向量。
- 手工关系立即显示。
- AI 关系仅以建议列表存在，用户接受后成为边；拒绝结果用于本画布去重，不自动再次建议。
- 关系类型：`similar-style`、`same-component`、`same-project`、`supports`、`contrasts`、`derived-from`。

### 4.6 一键整理

系统根据语义、颜色、组件和已有位置返回分组、标题、关系和目标位置。预览期间不写入画布；应用时校验基准版本，版本冲突则要求重新生成。应用形成单个历史操作，可一步撤销。

### 4.7 输出与分享

- 单项可复制色值、CSS 变量、文字、标签和已确认切图。
- ZIP 固定包含 `design.md`、`tokens.json`、`variables.css`、`components.md`、`copy.md`、`sources.json`、`elements/`。
- 只读分享使用高熵令牌，可随时撤销；访问者不能看到所有者邮箱、AI Key 或私有画布导航。

## 5. 功能优先级

### P0

账号/邀请、画布 CRUD、六类卡片、图片/网页/文字采集、自动保存、撤销/重做、单素材分析、元素确认、搜索、关系、整理预览、资产包、只读分享、额度/BYOK。

### P1

手动画布快照、分析质量反馈、批量分析、更多组织布局、浏览器插件商店发布。

### P2

PDF/视频、Figma、异步评论、团队空间、移动端、订阅与正式大陆运营。

## 7. 异常与安全

- 未授权读写返回 401/403；不存在或已撤销分享统一返回 404。
- 上传按真实 MIME、文件头、尺寸和像素数校验，拒绝 SVG/HTML 与图像炸弹。
- URL 仅允许 HTTP(S)，DNS 解析和重定向每一步都阻止私网、环回与云元数据地址。
- 网页正文清洗后保存，禁止在产品域执行采集来的脚本或 HTML。
- BYOK 只允许白名单服务商端点，AES-GCM 加密，日志脱敏，可立即删除。
- 删除账号级联清除结构化记录、对象、向量、分享和密钥。

## 8. 验收指标

- 结构化分析首次或一次修复后成功率至少 95%。
- 500 张普通卡片在参考 Windows 中端设备平移/缩放平均不低于 45 FPS。
- 刷新、断网恢复、重试不丢失已确认画布数据。
- 所有导出结论可追溯到素材，推断值明确标记。
- 整理撤销精确恢复位置、分组和连线。
- 非所有者不能访问私人素材；撤销分享后原链接返回 404。
