# InspoAtlas 浏览器插件使用指南

## 安装开发版

1. 在项目目录执行 `pnpm extension:build`。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择 `apps/extension/.output/chrome-mv3`。
5. 将 InspoAtlas 固定到浏览器工具栏，方便随时采集。

## 采集网页

1. 先打开 InspoAtlas Web 端并完成登录。
2. 打开想保存的普通网页或 SPA 页面。
3. 点击浏览器工具栏中的 InspoAtlas 图标。
4. 确认“接收地址”：
   - 私有线上版使用 `https://inspoatlas-beta.glad-morel-5947.chatgpt.site`。
   - 本地开发使用 `http://localhost:3000`。
5. 点击“采集到灵感图谱”。插件会依次采集页面标题、来源 URL、正文、关键元素样式和分段全页截图。
6. 回到 Web 端，在当前画布中查看新素材并继续 AI 分析。

插件只会在用户主动点击后读取当前标签页，不会读取 Cookie，也不会在后台持续浏览。浏览器内部页面、扩展商店页面和部分禁止脚本注入的页面无法采集。

## 常见问题

- 提示“请先打开并登录 Web 端”：先在同一个浏览器中打开接收地址并登录，再重试。
- 提示“保存失败，请检查接收地址”：确认接收地址没有多余路径，并且本地开发服务正在运行或线上站点可以访问。
- 页面很长时会被拆为多段截图；当前安全上限为 30 段或 40,000px。
- 修改插件代码或切换构建后，在扩展管理页点击“重新加载”。
